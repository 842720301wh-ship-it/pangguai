# Android 测试版

应用名：水到渠成。包名：`com.panguai.account`。当前版本 0.4.0 / versionCode 4，最低 Android 8，arm64-v8a。显示名与 APK 文件名前缀从根目录 `package.json` 的 `panguai.displayName` 读取。包名、JNI、签名和既有账号加密格式保持兼容，可覆盖更新，勿卸载以免丢失手机私有账号。

## 打包

在项目根目录执行 `npm run build`，输出 `release/Android/水到渠成-0.4.0-debug.apk`。它会检查 Go 测试/vet、前端类型与模板，再构建前后端和 APK。工具路径与可配置环境变量见根 README。构建不自动安装；首次下载公开 AndroidX/ZXing 依赖需要网络。

## 原生能力

Java WebView 通过 JNI 启动内嵌 Go 随机回环服务，Vue 和 API 同源。手机首次运行生成独立密钥和客户端标识；电脑账号、密钥、手机号、验证码和 MCP 令牌不打入 APK。

- **扫码**：右上角直接打开原生相机。使用 ZXing Android Embedded 4.3.0，仅识别 QR；无图片保存、相册读取或原始码日志。返回解码文本给本机 API，提取 NQT/IMEI/SN，固定请求平台解析接口，不打开二维码网址，不自动启动。取消或拒绝相机权限可返回。
- **定位**：点击启动后申请前台精确定位。LocationManager 获取 GPS/网络定位，限时 25 秒，接受 60 秒内且精度不超过 200 米的位置，结束后移除监听。系统定位关闭、权限不足或超时会阻止启动。无后台定位、轨迹记录或高德私有 Key。OS WGS84 坐标由后端转换为原客户端使用的 GCJ02 格式。
- **启动**：在设备卡片选服务，再点启动。后台仍校验设备状态和完整计费信息；费率变化需要用户再次点击。请求结果以提示条显示，取消底部确认抽屉与成功对话框。计量设备仍按平台实际用量结算。
- **使用状态**：校区入口已移除。启动回执确认、状态与时长持续同步，按每台设备的远程结束能力提供本次会话终止；结束确认后解除本次锁定。费用未回传时显示待结算。当前功能与验收范围见 [项目说明](../README.md#功能与进度)。

产物 Manifest 已核验：INTERNET、CAMERA、ACCESS_FINE_LOCATION、ACCESS_COARSE_LOCATION，以及 AndroidX 的本应用签名级内部 receiver 权限；没有后台定位或存储读取权限。相机和精确定位必须由用户在手机上授权，不使用 ADB 自动授权。

WebView 拦截外部资源与导航；用户点击项目仓库链接时交由系统浏览器打开固定的 GitHub 项目地址。文件/内容访问、DOM 存储、混合内容和表单保存禁用。API 仅在回环地址监听，关闭应用备份；CSP 禁止 iframe 和外部脚本。Go 对平台 HTTPS 保持证书校验。构建和安装不设置全局代理、VPN、证书或 Root。

“我的”新增四个独立页面，无需登录即可访问。赞赏码与 QQ 群码随应用打包；保存按钮调用系统文档选择器，由用户选择保存位置，不新增存储权限。复制群号通过系统剪贴板完成。详情页支持顶部返回与系统返回，刷新后保留所在页面。可运行 `npm run check:ui:about` 检查导航、图片原样下载、剪贴板、原生回调及手机布局；原生保存界面及外部浏览器跳转仍需实机验收。

## 验收

`npm run check:ui` 使用完整网络拦截与原生桥模拟，验证金额、两页导航、校区筛选、绿/红状态点、定位失败/过期、费率变化、直接启动及扫码回调。它不证明相机/GPS 硬件与平台实际设备操作已验收。

0.4.0 进一步验证动态状态、计时、刷新会话恢复、结束请求幂等、等待平台结束确认、按设备能力隐藏不支持的终止按钮、后台暂停与旧版缺失时间兼容。校区入口已移除。

本轮完整在线及缓存离线构建均成功，0.3.0 已通过 ADB 覆盖安装并进入主界面，实机页面确认余额 ¥43.49 / ¥29.70 和两台设备正常显示。签名与 0.2.0 一致，安装未清除数据；安装后相机、精确与大致定位权限均为未授权。

后续 0.4.0 也已通过根目录离线构建，覆盖安装返回 Success，设备核验 versionCode=4 / versionName=0.4.0。签名和原包名保持一致，没有自动授予权限、发送实物指令或清除账号。实际终止流程仍待本人测试。

实机测试：点右上角扫码并按系统提示允许相机，对准本人设备码，检查加入列表。随后在本人设备旁选服务并点击启动，允许精确定位。扫码得到的设备若尚无平台可确认状态，将显示“待确认”，不可假定空闲。本助手发起且已确认的会话在设备支持远程结束时可点终止；其他使用请在官方 App 核对。相机真实识别、GPS 与实际设备启动尚待用户验收。
